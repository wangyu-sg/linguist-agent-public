# 领域行为验收矩阵

使用现有测试套件，下面不是要求创建对应数量的测试文件。纯数据和Fake Provider只证明合同；真实模型选择与语言质量另看linguistic-cases。

|---|---|---|
| B01 | 连续两页，第一页有非阻断TM待查 | 后续独立内容可读；相关正式完成仍等待查验，不每页收尾 |
| B02 | 一个核心名词影响后续多段 | 定向优先查该名词，不盲推整批，也不阻断无关项 |

| B23 | 长历史压缩/恢复 | 仍原生Pi；旧CAT决定不清；不重复成功写入，未知模型窗口不编数值 |
| B24 | 原生Agent/Chat/Automation/MCP/Skills | 通用能力无削减，不新增独立侧栏/运行时；既有smoke实际执行 |

## 简单字段/载荷基准

构造相同内容的旧/新context输出，对比事实、source-ref关系、UTF-8字节和分页，不以删必要内容换成绩。另构造有很多元数据的长参考，统计实际重复text范围；没有重复的样本不强求比旧版本更小。

对脚本/文件结果比较：第一次完整语言阅读必须完整，机械统计只返回统计。测试不能只检查“返回字符少于X”，还必须确认需要判断的内容没有被隐藏。

## 发布门槛证明层次

implemented / deterministic-tested / model-tested / packaged / installed / production-measured分开记录。没有真实语言运行就不能写model-tested；没有安装就不能以asar生成替代installed。重复失败的用例保留记录，不靠重试出一次PASS结案。
