# 三个集成任务包：复用案例，不追加大型基准

这些是独立合成集成任务，不是客户生产，也不是额外36×3轮生成。优先复用同一次岗位案例运行的内容与输出，只为合同联动需要的少量样本重新调用。不得将 linguistic-cases.json 的 evaluation 字段或本文件预期结果交给被测Agent。

## I1：没有SG的新项目，完整TEP责任

输入：T08（装备品阶）、T10（护盾排除自身）、T12（松开射箭），以及各自brief。提供最小CSV/对象，不提供不存在的SG/TM。

用户任务：把这组文本翻成简中，完成TEP，生成完整结果文件与简短差异/未决报告；不向外部平台写入。

验证：General不阻塞在不存在资产上；T能自然成句且保留全部条件；E读取这次T的全部源译，而不是只看差异；P读取E的最新结果；成果和真实各阶段范围可追溯。可以复用原生委派，不自动新建第二套会话系统或导入CAT。已约定TEP不等于必须恰好三个子进程；但同一人/同一上下文自查不能被报告为取得独立第二视角。

效率核对：完整输入不为计数在父任务重复打印；T/E/P各自取得必要文本不判作无用重复；无SG不生成空资产盘点报告。

## I2：人物语气与可接受译法，不把校对变重译

输入：T05、T09和T11用于新翻译；E05、E10、P03和P09提供既有文本与相应brief。混合任务保留每项语言方向和职责，不对已有合格项重跑T。

用户任务：处理指定的新译、双语审校及最终校对项，使人物与文本用途成立；已有合格表达保留。

验证：能重组信息而不增加剧情；保留叙事克制、轻微挖苦、悬疑节奏；不给所有内容套同一种术语/书面语。工具页小于这一逻辑组时，跨页判断不触发逐页提交和TM关卡。

本包仅含文字场景说明，不含实机图像。图片证据、字体截断和图文定位另用现有获准非客户图像fixture完成；若没有，标未验证，不把文字描述当成已看图。

## I3：有版本与范围的长期项目

建立合成项目资料：v1“所有名词都用标题式大写”；v2明确替代v1，规定普通UI句子使用sentence case，但一个fictional专名例外保留，另一个剧情场景不适用该UI规则。客户TM样本必须保留版本与来源标记，不用真实客户条目。

输入：E04、E06、P11及其brief；另有一页旧规则和一页更新。以 current/approved 等身份明确提供，不能让Agent仅凭文件日期排序。再加入两个同文不同来源的参考，以及多个句段共享的一份短规则。

验证：首次建立的适用规则基线完整；已有完整v2后不再全读v1。增量仅补新增规则；共享正文去重但来源/适用关系不丢。旧TM的数值不补进当前Source；倒计时缩写不扩散到完整叙述。

并发/恢复用合成CAT库：提交一组含成功、stale、locked和结构失败项；取得真实回执后另一写入者修改一个成功项。旧回执仍真实，但不能确认新版本。重放不会拿新revision替换历史；部分结果不让整批重做。
