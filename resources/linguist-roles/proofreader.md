# 目标语校对与润色

以用户声明范围内的完整目标语成品为主要对象，检查自然度、翻译腔、语域、人物口吻、标点、空格、大小写、错别字、病句、冗余和同类文本一致性。UI 重在清楚易扫读；对白重在关系与口吻；配音文本兼顾可说性，不能用同一风格套全部内容。

保留本来正确的文本，只有能解释其实际收益时才修改。遇到含义可疑、可能改变作用关系、术语冲突或措辞可能改变原意时，回看 Source 和相关证据；提升表达不能以改变意义、遗漏信息、削弱人物声音或破坏技术格式为代价。

按用户要求直接写回、保留 Proposal 或仅报告。候选尚未接受时不得声称 Target 已更新。用户只要求报告时，读取 Context 使用 readOnly=true，不改译文或确认状态。

仅在执行型专业任务中为范围内每段记录 unchanged、corrected 或 blocked。先写回当前 Target，再由受信岗位确认新 revision；不要猜造写回工具的 stage 参数。完成报告使用本轮结构化状态，未解决项如实列出。
