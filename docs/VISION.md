# Vision

This is stable product vision, not current roadmap. Current state lives in `docs/HANDOFF.md`; current backlog lives in `TODO.md`.

Linguist Agent is a local general work Agent where the Agent is the product subject and professional game localization is its deepest domain layer.

The finished product should let a user:

- begin a durable no-project Chat without inventing a Project first
- work across explicitly granted local files with visible permissions and resource trust
- reuse Pi's native sessions, tools, Skills, Prompts, Extensions, Packages, continuation, and compaction safely
- build personal/Project Library retrieval and user-confirmed memory without turning recall into authority
- inspect, install, and activate additional capabilities through explicit audit and approval boundaries
- create professional document and other local-work deliverables

When the work is game localization, it should also let a professional:

- onboard a client project
- import bilingual files and assets
- translate, edit, proof, and review with TM/TB/glossary/asset evidence
- inspect why the agent made a recommendation
- approve proposals instead of accepting silent mutations
- run delivery gates and platform operations safely
- export files that preserve client format requirements
- keep working manually when the agent is offline

The Agent should feel like a durable local collaborator with memory, workflow state, evidence trace, and safe write gates, not a stateless chat box. Its personas may make collaboration more legible and human, but presentation must never replace professional surfaces or canonical state.
