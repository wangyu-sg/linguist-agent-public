## 本次变化

- 三模式共用原生侧栏、顶栏、消息、输入框和右侧工作区；保留 CAT 领域内容、岗位和项目身份、授权及结构保护。
- 恢复上游审批区、会话拖入引用、队列与消息排版、文件/Markdown/浏览器菜单行为；移除额外的窄窗强制折叠和右区隐藏。
- 统一导航代际与最近访问记录，修复项目会话恢复、冷启动收起状态、设置入口、改名显示及同名预览身份。
- 后台终端不再依赖右栏挂载来收集事件；隐藏的子任务不清查看提醒，展开后再清。两项均为在上游现有路径上确认的修复。
- 继续新任务与重试保留正确的项目、岗位和原轮次范围；解绑后同步模式。
- Pi 0.86.1 保留原生生命周期和请求路径；本轮发现的项目指令通过原生轮末队列交付，避免规则发现后工具在同一任务中持续被阻断。

## 基线与安装包对照边界

公开 `v0.19.57` 与 `v0.19.62` Tag 指向同一 commit；该公开源码的 App 版本仍为 0.19.57。另行只读检查的 0.19.62 安装包具有不同版本信息与额外同步进度接口。对照已覆盖 Agent/Chat 顶栏、主区显示条件、中心标签栏、右区菜单及主要布局路径；不能据此证明整个安装包与公开源码相同，不能宣称完整合入 0.19.62。
