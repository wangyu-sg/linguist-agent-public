# Pi capability parity

This matrix records LA product mappings to the pinned Pi API/CLI. The authoritative catalog is generated by `/api/pi/usage` from current Pi sources; this document is an orientation aid, not a copied CLI specification.

| Area | LA surface | Boundary | Evidence |
| --- | --- | --- | --- |
| Settings | `/api/pi/settings`, Electron Settings | Global/project values, effective source, type/range validation, global-only enforcement | `tests/pi_settings_parity.test.ts`, desktop Settings tests |
| Provider auth | provider catalog, Keychain/API-key env, Pi OAuth login/logout | Secrets stay in Keychain or official env references; ambient Bedrock/Vertex credentials are diagnosed without copying values | `tests/pi_keychain_credentials.test.ts`, `pi_provider_auth`, `pi_auth_login` |
| Custom models | structured and raw `models.json` editor | Preserve unknown fields; expose supported provider/model fields; do not persist literal secrets by convenience | `tests/custom_models_document.test.ts` |
| Packages | `/api/pi/packages` and `/action` | Catalog reads do not install; install/remove/update requires trust/confirmation; Pi self-update is not exposed | `tests/pi_packages.test.ts`, `pi_package_executor.test.ts` |
| Resources | Package and top-level extension/skill/prompt/theme visibility/toggles | Use Pi `+path`/`-path` filters and DefaultPackageManager resolution; active sessions may require reload/restart | `tests/pi_packages.test.ts` |
| Task Package | Task-scoped resource profile preview/apply and immutable Run manifest | Revision/plan hash, trust, executable approval, recursive integrity, no client-authored paths | Task Package/profile/resource tests |
| Keybindings | `/api/pi/keybindings`, Electron Settings | Official global file, key validation/conflict hints, unknown action preservation, restore default | `tests/pi_keybindings.test.ts`, desktop Settings tests |
| Themes | `/api/pi/themes`, Electron Settings | Built-in/global/project/settings/Package sources and required-token validation | `tests/pi_themes.test.ts` |
| Sessions | `/api/pi/sessions`, advanced Settings | Historical JSONL list/tree/name/delete/fork/clone/export/share only; canonical Task continuation does not Resume from this panel | `tests/pi_sessions.test.ts` |
| One-shot run options | next Task/CAT turn settings | Tool/resource allow/deny, trust override, extra resources, and no-session where supported; no CAT system-prompt replacement | `tests/agent_run_options.test.ts` |
| CLI I/O shapes | `/api/pi/usage` parity card | Product equivalents are identified; raw stdin/stdout RPC, URL/query API-key secrets, and arbitrary `@file` Settings shortcuts remain intentionally unsupported | `tests/pi_usage_parity.test.ts` |
| Trust/security | Pi trust plus LA CAT rails | Project trust controls resource loading, not CAT write authority or sandbox guarantees | `tests/pi_trust.test.ts`, runtime security tests |

Recheck this matrix only when Pi pins or LA mappings change. Do not add a compatibility wrapper merely to make a row look complete.
