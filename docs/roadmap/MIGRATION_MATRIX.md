# Linguist Agent 增量迁移矩阵

基线：`64bcb15b`。用户已批准大改方向，但迁移仍必须按单一不变量工单推进；禁止一次性重写和永久双轨。

## 1. 迁移总原则

1. 先加 characterization/failure test，再建立 seam。
2. 新实现以 adapter 包住旧实现；一个工单只迁一个 authority。
3. 数据迁移先扫描、备份、导入、校验，再切 writer；不先删旧数据。
4. 同一时刻只能有一个 canonical writer/状态机/权限决定者。
5. shadow read 可以短期存在；永久 dual write 不允许。
6. 回滚只能回到完整旧版本/旧数据视图，不能拼接一半新旧状态。
7. 每阶段保持 CAT locked/proposal/evidence/QA/delivery hard rails。
