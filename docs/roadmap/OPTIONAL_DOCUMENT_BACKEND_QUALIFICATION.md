# Optional Document Backend Qualification Boundary

LA-031 keeps every optional document backend disabled unless its managed lock passes an exact server-side qualification record. The MinerU record must bind the pinned runtime/package/model digests, a macOS Apple-Silicon hardware observation, CJK CER, reading-order, table-cell, peak-memory and crash records, plus a license-evidence digest. Unknown or missing fields leave the pack `unqualified`.

The former Asset parse command/environment override and its standalone process/cache/output implementation are deleted. The UI receives an explicit `unavailable` state and no cache/output is created; there is no fallback or second active route.

There is no checked-in qualified MinerU record, no installed optional pack, and no real corpus, hardware, license, crash or quality evidence in this campaign. MinerU, Unlimited-OCR, and remote parsers remain blocked. No real `data/**`, customer file, credential, public mirror, or release material was read.
