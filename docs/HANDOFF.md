# Linguist Agent 当前交接

本轮已公开发布：同步公开 Proma 基线、恢复三模式原生界面与导航，并修复右侧工作区及项目会话接缝。发布源码对应的远程 CI 和 Release 工作流成功，安装包与更新资产已上传；实际下载哈希、签名和更新清单核验通过。用户随后授权替换日用安装，正式包已启动且手动检查更新成功。源码版本与范围见 [当前事实](../CURRENT_FACTS_SIMPLE.md)，已取得和仍缺的证据见 [本次发布验证](./release/VALIDATION_0_18_1.md)。

## 仍缺证据

- 下一版本的自动下载与安装全链仍待实际验证；本轮已经验证日用界面检查更新成功。
- 人工及长期资格按已有未完成项继续记录。

旧日用修复包缺少更新配置，真实 updater 读取复现 `ENOENT`。已按用户后续授权使用正式包替换并备份旧应用，恢复更新入口；项目与会话保留。

已完成的定向验证包括状态恢复、项目切换竞态、受管预览、项目设置/改名、后台终端及 continuation 绑定；隔离打包界面已核验窄窗顶栏、从 Files 打开项目设置、右栏收起后的 Renderer 冷恢复与展开。这些结果不替代全部 UI、所有平台或人工无障碍资格。

另行比较的较新 Proma 安装包仅作局部主界面对照；公开 Tag 与当前采用的源码基线相同，包内仍有额外同步接口，不能记为完整源码升级。Linguist 继续作为 Proma 的第三模式，与通用 Agent 共用原生 Agent 界面和右侧工作区；Chat 保留原生 Chat 路径。

前一版本的完整历史证据保留在 [前一版本实施与发布验证](./release/VALIDATION_0_18_0.md)；本版本不继承该版本的语言资格。真实 Phrase 校准、自动更新全链及其他人工证据仍见 [TODO](../TODO.md) 和 [已知限制](./release/KNOWN_LIMITATIONS.md)。
