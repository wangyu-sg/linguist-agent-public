# Linguist Agent 当前交接

当前工作是下一版本发布候选：同步公开 Proma 基线、恢复三模式原生界面与导航，并修复右侧工作区及项目会话接缝。尚未公开发布、未替换日用安装。源码版本与范围见 [当前事实](../CURRENT_FACTS_SIMPLE.md)，已取得和仍缺的证据见 [本次候选验证](./release/VALIDATION_0_18_1.md)。

## 收口顺序

1. 记录正式合并 commit，并同步机读基线、About/Diagnostics 基线信息及上游触点登记。
2. 完成最终候选的完整回归、边界、类型、构建和隔离打包验证；侧栏行内快捷键间距的最终修改需重新核验。
3. 核验公开树及新增可达历史的署名/隐私后提交、推送，等待 CI 和 Release 工作流实际完成，再回填资产、签名、哈希与更新元数据证据。
4. 用户通过在线更新安装；本轮不替换日用安装，不把 Release 存在当作端到端更新已验证。

已完成的定向验证包括状态恢复、项目切换竞态、受管预览、项目设置/改名、后台终端及 continuation 绑定；隔离打包界面已核验窄窗顶栏、从 Files 打开项目设置、右栏收起后的冷启动恢复与展开。这些结果不替代全部 UI、所有平台或人工无障碍资格。

另行比较的较新 Proma 安装包仅作局部主界面对照；公开 Tag 与当前采用的源码基线相同，包内仍有额外同步接口，不能记为完整源码升级。Linguist 继续作为 Proma 的第三模式，共用宿主、会话、输入框和工作区。

最近已公开版本的完整历史证据保留在 [前一版本实施与发布验证](./release/VALIDATION_0_18_0.md)；本候选不继承该版本的发布或语言资格。真实 Phrase 校准、自动更新全链及其他人工证据仍见 [TODO](../TODO.md) 和 [已知限制](./release/KNOWN_LIMITATIONS.md)。
