# Project overview

Linguist Agent `v2.32.7` is a Pi-native, local-macOS-first general work Agent with a professional game-localization layer.

- Maintained client: Electron under `apps/desktop`.
- Runtime: authenticated loopback `cat-server` plus Pi.
- Canonical model: standalone or Project-owned Task / Run / Agent thread / Activity / Artifact / Decision.
- General surfaces: no-project Chats, explicit file grants, Library/RAG, confirmed memory, Package Center, managed documents, and Maintainer.
- Localization layer: Project/Batch/Segment evidence, CAT, Team, QA, and Delivery.
- Source truth: `packages/cat-data`, `cat-runtime`, `cat-tools`, `cat-formats`, `cat-server`, and `apps/desktop`.
- Open work: `TODO.md` only.

Use `README.md` for commands, `PRODUCT.md` for stable principles, and `docs/ARCHITECTURE.md` for implementation boundaries.
