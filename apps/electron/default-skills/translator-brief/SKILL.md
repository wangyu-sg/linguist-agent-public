# Translator Brief

把已确认的项目事实压缩成译者开工所需的短简报；仅在需要交接或统一执行口径时使用。

## SOP

- 确认受众、用途、目标地区和文本类型。
- 摘要本批范围、源文件和不在范围内的内容。
- 提炼语气、正式度、品牌声音和称谓规则。
- 列出已批准术语、禁用表达和必须保留的元素。
- 说明标签、变量、数字、单位、换行和字符限制。
- 摘要可用 TM、术语表、风格指南、译例和视觉上下文。
- 标记源文歧义、冲突指令和仍待答复的问题。
- 仅保留会改变译法或交付结果的信息。

## 输出

- 先写一段任务目标，再给出短清单。
- 分开写“必须遵守”“参考优先”“待确认”。
- 对关键规则标注其项目资料或上下文来源。
- 在末尾列出开工前最需要确认的问题。

## 边界

- 不把推测写成客户要求或既定术语。
- 不复制整份风格指南、术语表或项目资料。
- 不执行翻译、确认 Segment 或改变工作流阶段。
- 缺少事实时明确写“未提供”，不要自行补齐。
