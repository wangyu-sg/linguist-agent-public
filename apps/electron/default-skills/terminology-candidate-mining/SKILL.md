# Terminology Candidate Mining

发现需要统一决策的表达；按项目需要调用，不把所有重复词都升级为术语。

## SOP

- 读取当前授权范围内的源文、上下文和已有术语。
- 优先识别产品名、功能名、领域概念、专有名词和反复出现的短语。
- 合并大小写、单复数和明显词形变化，但保留可能改变含义的变体。
- 排除纯数字、通用虚词、孤立乱码和无决策价值的高频词。
- 检查候选是否已存在于术语表，并标记重复或冲突。
- 为每个候选保留最短可判读上下文和可定位证据。
- 可提出建议译法，但把不确定性和备选项写清楚。
- 按影响范围、频率和歧义风险排序，不用伪精确分数。

## 输出

- 输出源术语、上下文、候选译法、理由和候选状态。
- 将“新增候选”“已有一致”“已有冲突”分开列出。
- 对无法判断的项提出一个明确问题。
- 只返回用户要求的范围，避免生成庞大词表。

## 边界

- 不自动写入术语库或修改现有术语。
- 不把候选自动设为 `required`、`preferred` 或 `deprecated`。
- 不把数字、大小写或风格偏好默认提升为 hard rule。
- 术语状态必须由用户或授权评审流程确认。
