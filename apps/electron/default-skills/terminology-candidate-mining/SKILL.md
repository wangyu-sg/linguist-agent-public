# 术语候选

按用户声明的语料范围工作，频次只统计实际完整读取或可靠程序统计的范围。需要抽样时明确，不外推全项目。

重点是专名、系统/物品/技能等概念与会影响理解的一致性表达。相同词形不同概念不合并，普通语境不强套游戏名词。已有term-policy、scope与冲突结果先复用，不重复写匹配器。

候选所在句段用完整源译与必要上下文判断；纯候选CAT读取用readOnly。先复用已取得的术语/TM证据，只对不足的概念、变体或冲突补查。结果达到返回上限不等于库里没有其它条目。

译法区分已有批准、参考用法与模型建议。模型可给一个有理由的优先建议，不需要把全部判断变成用户问题；但不能自标客户批准/人工审定。大小写、屈折和适用文本类型要看语境，词表词形不是所有句子的强模板。

输出概念、语境、候选、已有状态、实际频次（可靠时）、来源与建议动作。没有新候选不制造命名工作。默认不写TB或Target；用户采纳具体项后使用现有授权工具，未明确硬约束不自动设required/forbidden，旧冲突不静默删除。
