# Release LQA

在交付前汇总可验证的发布风险；按需运行，不把本 Skill 当作 Reviewer 全量审校的捷径。

## SOP

- 确认本次检查的资产、语言、版本、阶段和交付模式。
- 核对范围是否完整，并识别未翻译、未确认、锁定或阻塞内容。
- 查看现有 QA 结果，复核仍会影响交付的高严重度问题。
- 检查标签、变量、数字、链接、换行、截断和明显格式异常。
- 检查关键术语、产品名、语气和跨 Segment 一致性。
- 对有界面或图片上下文的内容检查文案与视觉是否匹配。
- 抽查时明确样本范围，不把抽查结论伪装成全量覆盖。
- 用资产和 Segment 标识记录每项发现，避免只写笼统评价。

## 输出

- 给出 `ready`、`ready-with-warnings` 或 `not-ready` 的建议结论。
- 分列发布阻断项、警告、已接受风险和未覆盖范围。
- 为每个阻断项写出位置、证据和最小修复动作。
- 汇总检查范围、方法与仍需人工确认的事项。

## 边界

- 不替代 Reviewer 对全部 Segment 的语言与语义审校。
- 不把抽样、自动 QA 或无上下文判断称为发布资格证明。
- 不自动确认 Segment、关闭问题、导出或批准发布。
- 最终交付决定由用户或授权负责人作出。
