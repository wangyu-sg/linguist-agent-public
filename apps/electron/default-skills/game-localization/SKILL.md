# 游戏本地化作业

目标是玩家能理解、愿意读、在实际语境中成立的译文。准确性、自然表达、人物声音和技术正确性共同构成质量；术语与QA只能支撑判断。

## 正常流程

1. **定界。**复用已知语言对、用途、当前批次/文件、预期产物和授权。小任务直接做；缺失的资料或用途信息足以影响结果时才补查，不先创建固定计划或要求用户重填简报。
2. **取得真正必要的依据。**使用有效项目基线、当前规则、相关术语/例句和必要上下文。必要规范尚未完整整理时不能只看增量；已完整有效则复用。先判断范围和版本，不按文件新旧或TM分数机械排序。
3. **连续语言判断。**按连贯内容和实际长度组织，读取分页不触发TM→写回→复读→确认关卡。T写目标语成品；E比较完整双语；P整体阅读目标语，对疑似误义回看源文。每阶段承担自己的完整质量责任。
4. **处理依赖而非停住整批。**影响当前含义或大量后续内容的疑点及时查询；其余显式必查按相关性成组补齐，相关完成/正式提交前闭环。独立内容继续，不因一个TM待查停止全部工作。
5. **收敛并提交。**候选只保留当前版本、实际裁定范围、必要修改和未决。用户已授权执行就用现有批量工具正式处理，不停在报告等催促；成功revision直接复用，冲突或未知只恢复相关项。完整结果由已有格式与数据能力组合，不每批重写解析器。
6. **按约定检查并收尾。**运行需要的QA/平台动作，分类实际问题与误报。模型或工具的自报状态不独立证明语言正确；分别报告语言裁定、必要查验、写入、Stage与平台状态。正常结果简短，完整明细留受控产物。

## 方法参考：只读取当前需要的部分

- 中译英存在省略关系、长串动作、机制句或翻译腔时，读 [中译英方法](references/zh-en.md)。
- 英译中存在长修饰语、被动结构、语体或欧化表达时，读 [英译中方法](references/en-zh.md)。
- 新语域、人物声音、双关、宣传、FPS/体育或运行拼接问题，读 [游戏文本与表达](references/game-texts.md)。
- 对审校尺度、规范覆盖、TM适用性、技术警报或判定误报有分歧时，读 [依据与质量判断](references/quality-evidence.md)。

熟悉的方法不必每组重读；参考未启用/不可得时，依据岗位责任和已有有效信息继续，不冒称读过文件。不将参考一次性全部装入上下文。

## 与其他能力的关系

不替代原生工具、权限、计划或协作。需要独立视角时用原生岗位与委派；交接传真实范围、关键依据、责任与产物位置，不传全部父历史。父任务不要重复阅读子任务已经正确保存的整个双语稿来数段或证明进度。

Phrase回填用对应平台Skill，消费已收敛差异，不边输入边重新逐词审校。明确只做报告时不写Target或确认阶段。纯文件任务无需强制进入CAT，已有CAT专业任务仍承担其真实版本与覆盖责任。

纯文件任务可用 `linguist_working_copy`：`prepare` 通过已有格式适配器生成完整双语工作稿；连续审读后，以分组裁定和必要修订调用 `assemble`。接续T→E→P时，`sourcePath` 始终指原件，`previousResultPath` 指当前工作稿，决策中的 `previousResultSha256` 使用该稿返回的 `artifactSha256`；`unchanged` 保留当前工作译文。复用原件 `sourceSha256`、稳定ID与原 `baseRevision`，不每组重新解析。各会话产物独立；交接使用工具返回的实际路径。结果中的 `changes` 是本阶段差异，`finalChanges` 是对原件的累计差异；未列ID仍未裁定。该JSON是完整私有工作稿，正式写回仍用对应CAT或平台工具。

有实质收益才修订；自然表达不是擅自增事实，准确也不是照搬源语语序。不存在唯一标准译文，不要求每句给多个方案或长理由。只有需要客户/权限决定的缺口才交给用户，其余按专业判断完成。
