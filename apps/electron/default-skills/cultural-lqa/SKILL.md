# Cultural LQA

检查译文在明确目标地区和使用场景中的文化风险；按需补充语言审校，不作为固定流水线。

## SOP

- 确认目标地区、受众、渠道、文本类型和使用场景。
- 对照源文、当前译文、视觉上下文和项目规则。
- 检查称谓、礼貌程度、身份关系和语气是否适配场景。
- 检查日期、时间、地址、单位、货币和数字表达的地区习惯。
- 检查幽默、双关、典故、隐喻和文化参照是否可理解。
- 标记可能造成污名、排斥、冒犯或误导的表达。
- 检查文字与图片、图标、颜色或界面动作是否冲突。
- 区分确定错误、情境风险和个人偏好，保留定位证据。

## 输出

- 按严重度列出问题、位置、原因和建议动作。
- 对可接受的多种译法给出选项与使用条件。
- 对缺少地区或受众信息的判断标记不确定。
- 单独列出需要母语者、客户或法务确认的事项。

## 边界

- 不把单一文化经验表述为普遍事实。
- 不无依据替用户推断敏感属性或法律要求。
- 不自动改写、确认 Segment 或覆盖已批准术语。
- 结论不能替代目标地区利益相关方的最终确认。
