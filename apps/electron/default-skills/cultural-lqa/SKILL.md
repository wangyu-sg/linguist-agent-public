# 文化与语用判断

使用目标地区、受众、游戏世界观、人物关系与文本功能作判断。已有资料足够就工作；只有缺失信息实质改变结论才补查。不从名字、口音或国籍推断敏感属性与客户立场。

取得完整相关源译和必要场景。CAT报告读取遵守readOnly。Voice和批准例句可复用，尚缺图像/动作时定向查看；文件名、目录和对图像的猜测不能作为已看证据。

检查表达会怎样被目标玩家理解：礼貌关系、讽刺、幽默、隐喻、文化说明、单位日期和图文配合。允许有依据的适配与创意；不得自动删情节、改立场或加刻板印象。一般语用判断可以专业完成，不机械要求用户/母语者逐条批准。

涉及当前现实、法律或客户政策而材料不足时，使用授权的可靠来源核验。事实未知就限制相应结论；真正需要客户决定的立场/尺度问题集中说明，其他内容继续。

区分确定错误、场景风险、合理变体与未验证事实。建议有具体用途收益，不伪精确打分，不因能想到不同说法就修改。授权修复时使用现有写入保护；只要报告则不改Target。不要把文化检查当作术语政策、QA忽略、阶段确认或发布授权。
