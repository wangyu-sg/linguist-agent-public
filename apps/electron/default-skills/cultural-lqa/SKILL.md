# Cultural LQA

只报告有上下文的文化风险；没有地区和使用场景时，先暴露信息缺口。

## 执行

1. **固定判断语境。** 用 `cat_project_summary` 确认语言对，并从用户或项目资料确认目标地区、受众、渠道和使用场景。用 `cat_get_segments` 分页读取指定范围；未指定范围时先限定资产或样本。
   - 完成条件：地区、受众、场景、Segment 覆盖和未覆盖部分均明确；缺少关键语境时不得给确定性文化结论。
2. **读取相邻与视觉证据。** 对待检查 Segment 分批调用 `cat_get_translation_context`，保留源文、当前译文、相邻文本、项目规则和 evidence id。项目上下文提供相关文档标识时，用 `cat_read_context_doc` 读取文本或受管图片；已知 speaker 时用 `cat_get_voice_context` 核对已批准声音证据。
   - 完成条件：每个发现都能定位到 Segment，并引用决定该判断的上下文或资料；读不到的资料进入待核验项。
3. **分类检查。** 检查称谓和身份关系、礼貌与语气、日期/单位/货币、幽默典故、敏感表达以及图文动作是否适配。把事实性错误列为“确认问题”，依赖场景的判断列为“情境风险”，只凭一般印象的判断列为“待外部核验”。
   - 完成条件：每项都说明为什么属于该类别；个人偏好和无证据概括已被移除。
4. **提出最小动作。** 对确认问题给出可执行修改方向；对多种可接受表达给出适用条件；对风险项指出需要母语者、客户、地区专家或法务确认的具体问题。
   - 完成条件：每个非确认问题都有明确核验对象，不以“可能不自然”结束。

## 输出

- **范围与覆盖**：地区、受众、渠道、资产/Segment 和分页或抽样说明。
- **确认问题 / 情境风险 / 待外部核验**：位置、证据、原因、严重度和建议动作。
- **未覆盖**：缺少的视觉、地区资料或人工确认。

## 边界

- 不把单一文化经验、模型记忆或个人偏好表述为普遍事实。
- 不推断敏感属性、客户立场或法律要求。
- CAT QA 和术语校验不能证明文化适配；没有可靠外部来源时只报告风险假设。
- 不自动改写、确认 Segment、修改术语或批准发布。
