# Localization Readiness

在翻译开始前检查输入是否足以安全执行；按需使用，不把它当成每个项目的强制关卡。

## SOP

- 确认源语言、目标语言、目标地区和交付范围。
- 核对批次文件是否可读，并记录格式、数量和明显损坏。
- 检查待翻内容与不可翻内容是否可区分。
- 检查标签、变量、占位符、富文本和换行等结构约束。
- 核对术语表、风格指南、参考译文和上下文是否存在且适用。
- 识别缺少上下文、源文歧义、截断文本和重复冲突。
- 核对工作阶段、截止要求、输出格式和验收条件。
- 用文件、资产或 Segment 标识定位每个问题；没有证据时标记为待确认。

## 输出

- 给出 `ready`、`needs-input` 或 `blocked` 的建议状态。
- 分列阻断项、非阻断风险和可直接开始的部分。
- 为每个待确认项写出一个可回答的问题。
- 给出最小下一步，不扩写成完整项目计划。

## 边界

- 不臆测客户要求、语言规则或缺失上下文。
- 不自动导入文件、修改 Segment、设置术语或推进阶段。
- 不因一般风险阻断可安全执行的独立范围。
- 最终是否开工由用户或项目负责人决定。
