# Localization Readiness

把准备度检查做成一次有界的证据盘点，不把它变成强制流水线。

## 执行

1. **固定范围。** 用 `cat_project_summary` 读取受绑定项目的语言对和总量，再用 `cat_list_assets` 分页列完用户指定范围；用户未指定时检查全部批次。不要向用户索取 `projectId`。
   - 完成条件：每个纳入或排除的批次都有 `assetId`、文件名和理由，分页覆盖数与工具返回的 `total` 一致。
2. **检查可执行输入。** 对范围内批次用 `cat_get_segments` 分页核对空源文、状态、锁定项和明显缺失上下文；用 `cat_scan_unknown_tag_patterns` 检查未知结构形状，用 `cat_list_term_conflicts` 检查术语冲突。工具失败或数据不可读时保留原错误类别，不猜测内容。
   - 完成条件：所有范围内批次均有检查结果；任何未读完的页都写入未覆盖范围。
3. **核对项目事实。** 只依据当前项目资料确认目标地区、文本用途、格式、术语、风格、视觉上下文和交付要求。项目已归档、范围无法识别、结构无法保护或交付要求互相冲突时记为 `blocked`；其他资料缺口记为 `needs-input`。
   - 完成条件：每项结论都能指向批次、Segment、术语冲突或项目资料；没有证据的判断均转成一个可回答的问题。
4. **给出建议状态。** 只有在范围完整可读且没有阻断项时才给 `ready`；存在可补充信息时给 `needs-input`；存在无法安全执行的关键问题时给 `blocked`。
   - 完成条件：状态能由已列证据直接推出，且最小下一步对应每个未解决问题。

## 输出

- **范围与覆盖**：语言对、批次、已检查页数和未覆盖部分。
- **建议状态**：`ready`、`needs-input` 或 `blocked`，附一句证据化理由。
- **阻断项 / 非阻断风险 / 已具备条件**：每项带 `assetId`、Segment 或资料标识。
- **待确认问题**：一项一个问题；最后给最小下一步。

## 边界

- 不调用导入、写回、术语写入、阶段确认或导出工具。
- 不把缺少“锦上添花”的资料升级成阻断项。
- 未知 Tag 扫描不等于结构 QA；当前工具也不能证明 TM、TB、Style Guide 和 Context 已被完整盘点。
- 结论是开工建议，不是交付资格证明。
