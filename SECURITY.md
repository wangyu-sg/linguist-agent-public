# Security policy

Do not post credentials, customer files, private localization rows, runtime data, or unredacted diagnostic bundles in a public issue.

Report a suspected vulnerability through GitHub's private vulnerability reporting for this repository when available. If that channel is unavailable, open a public issue containing only a high-level description and request a private contact channel; do not include exploit details or sensitive material.

Security reports should identify the affected source version, operating system, impact, and the smallest synthetic reproduction possible. Installed-app, managed-runtime, provider, Package, and customer-data behavior must be distinguished from repository-source observations.
